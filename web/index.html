HiFlow Pro to Zigbee bridge

Installs release @TAG@ of the bridge firmware from the browser. The images hold no personal data: the bridge finds the inverter by its BLE name and takes the rest over Zigbee.

  1. Open pairing and leave it open: Add device in ZHA, Permit join in Zigbee2MQTT.
  2. Connect the board by USB and press Install below it. Pick the port named USB JTAG/serial debug unit.
  3. Tick Erase device on the first install. Unticked, a bridge keeps its settings and its pairing.
  4. Close the dialog after Installation complete! Its Next only leads back to the menu.

The installer cannot tell the ESP32-C6-LCD-1.47 and the XIAO apart (same chip). Pick the board you have: a bridge only takes updates for its own board.

After the install

  1. Check that it joined: it shows up as HMS-2000-4WB Bridge (the ESP32-H2-Zero about a minute later). If not, open pairing again and press RESET (or plug the board in again).
  2. Put the board at the inverter on a USB charger. It keeps its pairing. With one inverter in range it takes it after 5 minutes. With more, name yours over Zigbee. A Bluetooth PIN from the S-Miles app goes the same way: Settings over Zigbee.
  3. Check the values: they arrive once the bridge has logged in to the inverter. Until then its settings field shows what it is doing.
  4. Updates then come over Zigbee: Firmware updates from the releases.

If it does not work

  • The installer needs a browser with Web Serial: Chrome, Edge or Firefox 151+ on a computer.
  • On Linux the browser needs access to the port: add your user to the group uucp (Arch) or dialout (Debian, Ubuntu) and log in again.
  • Close other programs that use the port, such as an ESPHome log or a serial monitor.
  • Failed to initialize on a board with an older bridge: it sleeps, so its USB port does not answer. Close the dialog, press RESET and click Install within 3 minutes.
  • Still no connection: hold BOOT while you plug the board in, then press Install again. Afterwards press RESET or plug the board in again: otherwise it stays in the boot loader.
  • Without a browser: esptool, see Quick start with a release image.
