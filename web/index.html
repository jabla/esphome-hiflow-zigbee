HiFlow Pro to Zigbee bridge flasher

Installs release @TAG@ of the bridge firmware over USB and sets it up.

Needs Chrome, Edge or Firefox 151+ on a computer.

Your board, connected by USB

The Bluetooth connection PIN from the S-Miles app, not the account password.

Several inverters in range?

The bridge's answer lists the ones it sees.

Needed on the first install over other firmware. Clears the pairing and the settings.

Pair

  1. Open pairing: Add device in ZHA, Permit join in Zigbee2MQTT.
  2. Put the board at the inverter on a USB charger. It joins as HMS-2000-4WB Bridge. A bridge paired before needs no new pairing, unless it was erased.

The values arrive once the bridge has logged in. Until then its status sensor shows what it is doing: status codes. Updates then come over Zigbee: Firmware updates from the releases.

If it does not work

  • On Linux the browser needs access to the port: add your user to the group uucp (Arch) or dialout (Debian, Ubuntu) and log in again.
  • No connection: hold BOOT while you plug the board in, then press Install again.
  • See Quick start to install with esptool.
